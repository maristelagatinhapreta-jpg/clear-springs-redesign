# 🎨 Clear Springs Redesign

## 📖 Sobre o Projeto

Projeto de redesign UX/UI desenvolvido para analisar e propor melhorias na experiência do usuário da plataforma Clear Springs.

O trabalho teve foco em acessibilidade, arquitetura da informação e oportunidades de conversão.

## 🎯 Objetivos

- Melhorar a navegação
- Aumentar a acessibilidade
- Melhorar a experiência do usuário
- Aplicar conceitos de UX/UI

## 🚀 Ferramentas e Metodologias

- UX Research
- UI Design
- Arquitetura da Informação
- Design Thinking

## ✅ Entregáveis

- Análise da interface
- Identificação de melhorias
- Recomendações de usabilidade
- Propostas de redesign

## 📚 Aprendizados

- Experiência do Usuário (UX)
- Interface do Usuário (UI)
- Acessibilidade
- Design Centrado no Usuário
